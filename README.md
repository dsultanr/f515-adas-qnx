# F515 ADAS QNX

Предупреждение об опасном сближении с фронтальной камеры Seres F515 / AITO M5.
Распознавание AutoSpeed INT8 работает на стороне QNX, на Hexagon DSP через штатный
SNPE. Android-приложение показывает объекты и предупреждения, подаёт звук,
устанавливает компоненты QNX и проверяет обновления.

Это комплект исходников версии **0.1.6** (`versionCode=7`, подготовка релиза): приложение, QNX-демон,
готовые компоненты для APK, исходная ONNX-модель, преобразования для SNPE,
средства сборки и тесты. История начинается с очищенного снимка проекта.

## Сборка

Для APK достаточно Linux, JDK 17, Android SDK (Build Tools 34.0.0, платформа API 30),
Python 3, `adb`, OpenSSL и `zip`. Gradle не нужен. Модель и проверенный `fcwd` уже
лежат в `app/assets/qnx/`; для этого варианта сборки Qualcomm SDK не требуется.

```bash
git clone https://github.com/dsultanr/f515-adas-qnx.git
cd f515-adas-qnx
export ANDROID_SDK_ROOT="$HOME/Android/Sdk"
./scripts/init-keys.sh
./build.sh
./tests/run-host-tests.sh
```

Результат: `build/F515AdasQnx-0.1.6.apk`. Полная инструкция, включая подготовку SDK,
пересборку QNX и собственную подпись: **[docs/BUILD.md](docs/BUILD.md)**.

Ключи ADB и подписи создаются локально в исключённом из Git каталоге `.local/keys/`.
Личная сборка подписана своим сертификатом: её нельзя установить поверх официальной
версии, а официальный облачный APK не пройдёт проверку совпадения подписей.
Для собственного ГУ нужно авторизовать свой ADB-ключ. Подробности:
[установка и ключи](docs/INSTALL.md).

## Что умеет версия 0.1.5

- Устанавливать QNX-компоненты из APK при первом запуске и восстанавливать частично
  повреждённую установку с проверкой SHA-256, размера и прав файлов.
- Копировать через NFS; при ошибке передавать полную модель через telnet.
- Показывать рамки, коридор движения, ведущую цель, TTC и диагностические скорости.
- Выдавать необходимые разрешения через локальный root-ADB или открывать системные настройки.
- Загружать обновления с `tm.dsr.su`, проверять APK и устанавливать с системным подтверждением.
- Запускаться автоматически по желанию пользователя; по умолчанию автозапуск выключен.

Для перехода **с официальной 0.1.3** установите официальный 0.1.5 поверх старого APK,
без удаления приложения. Настройки сохраняются. [Установка и восстановление](docs/INSTALL.md).

## Снимок для калибровки

В 0.1.6 добавлена кнопка **«Сделать снимок для калибровки»**. Она получает кадр
камеры, показывает предпросмотр и сохраняет ZIP: полный PNG 1920×1080, исходные
пиксели UYVY, точный вход сети RGB 1024×512 и параметры в JSON. Доступны сохранение
в «Загрузки/F515AdasQnx» и отправка архива через выбранное приложение. [Подробности](docs/CALIBRATION.md).

## Состав

| Каталог | Содержимое |
| --- | --- |
| `app/` | Android Java, manifest, ресурсы, звук, готовые `fcwd` и DLC |
| `native/` | C++ QNX-демона, стартовый код, адаптация ABI, Docker-сборка, импорт зависимостей |
| `models/` | FP32 ONNX, преобразования графа, калибровка и сборка INT8 DLC |
| `scripts/` | Локальные ключи, контроль payload, подготовка метаданных релиза, проверка публикации |
| `tests/` | Проверки на компьютере и инструментальные тесты Android |
| `docs/` | Установка, сборка, устройство, протокол, ограничения и результаты проверки |

Закрытые SDK и библиотеки прошивки не переиздаются: для пересборки `fcwd` они
импортируются из вашей локальной копии с проверкой хэшей. Личные записи камеры,
дампы ГУ, ключи, пароли и готовые APK в Git не включены.
[Зависимости и происхождение](THIRD_PARTY.md).

<details>
<summary><b>Технические подробности реализации</b></summary>

Камера AIS/QCARCAM передаёт UYVY 1920×1080; CPU выполняет обрезку и преобразование
в RGB 1024×512. SNPE 1.55 запускает AutoSpeed INT8 на DSP без CPU fallback.
На QNX CPU выполняются DFL-декодирование трёх масштабов YOLO, NMS, сопровождение
объектов и два канала предупреждения: TTC по росту рамки и оценка дистанции/IDM.
Android получает JSON по TCP 62715, без потока видео.

Компоненты размещаются в `/var/log/fcw/apk_<id>/` и проверяются на стороне QNX
до запуска. Исполняемый файл копируется в `/dev/shmem/fcwd`, поскольку постоянный
каталог расположен на разделе с ограничением исполнения. Повреждённые объекты
сохраняются под именами `.broken_*`. Резервная передача использует foreground
OpenSSL и EOF в telnet, чтобы большая модель не блокировалась на эхо терминала.

Измерения на тестовом ГУ: около 14–15 обработанных кадров/с, препроцессинг 23–27 мс,
DSP около 36 мс, постобработка около 0,2 мс. Это результаты конкретного стенда,
а не обещание производительности на любой прошивке.

Приложение выдаёт предупреждения; команд управления тормозами или рулём нет.
Расшифровка скорости PPS и отображение выбранного кода предупреждения на приборке
ещё требуют проверки в соответствующих условиях. См. ограничения в документации.
