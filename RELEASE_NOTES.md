0.1.5

• Проверка бинарника QNX и модели по SHA-256; комплект устанавливается в отдельный каталог и проверяется до запуска.
• Исправлены обработка ошибок NFS, таймаутов ADB и отмена автозапуска во время копирования.
• Проверка обновлений и установка через tm.dsr.su с проверкой размера, SHA-256, пакета, версии и подписи APK.
• Кнопка выдачи прав на установку обновлений и работу без оптимизации батареи через локальный root-ADB.
• Автозапуск остаётся добровольным; работающий fcwd автоматически не перезапускается при обновлении APK. Новый комплект применяется при следующем запуске fcwd.

• Восстановление пустой и частичной установки, отдельная кнопка проверки компонентов, корректный возврат приложения после первой выдачи права на установку.
• Переход с 0.1.3: установить этот APK поверх старого, не удаляя приложение; последующие обновления доступны из приложения.
• Резервная передача компонентов через telnet при ошибках штатного NFS, в том числе при ложном успешном копировании нулевых файлов.
• Основная запись в NFS переведена с cp на dd + sync; хэш проверяется на стороне QNX до применения.
