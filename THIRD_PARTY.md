# Происхождение и внешние зависимости

## AutoSpeed и Vision Pilot

- [AutoSpeed / Autoware Foundation](https://github.com/autowarefoundation/auto_speed)
  — исходная модель обнаружения объектов в полосе.
- [Vision Pilot / Autoware Foundation](https://github.com/autowarefoundation/vision_pilot)
  — исходные веса AutoSpeed и подход к оценке CIPO/дистанции/IDM.
- Лицензия этих upstream-проектов: Apache License 2.0, копия в
  [licenses/Apache-2.0.txt](licenses/Apache-2.0.txt).

Исходные веса получены из `VisionPilot/modules/models/weights/autospeed_fp32.onnx`.
Версия весов в локальной истории соответствует коммиту
`e7e5c614832f175f1f9f10a0d0c0df2559ff2c38` upstream Vision Pilot.
Включённый `models/autospeed_fp32_opset12.onnx` — локально преобразованная версия
для старых runtime: статический вход, opset 12, представление Conv1D через Conv2D,
сохранение семантики Softmax. Веса не переобучались. Последующие изменения для
SNPE и квантизация описаны в [models/README.md](models/README.md).

`native/src/vp_fcw.*` — адаптация подхода Vision Pilot к QNX, с отдельными
изменениями знака скорости сближения, IDM и ограничением минимальной скорости.
Авторство upstream-компонентов сохраняется за их авторами; публикация адаптации
не означает, что проект одобрен Autoware Foundation.

Android-обвязка выросла из локального проекта F515 ADAS / distance-cluster:
доступ к ADB, VHAL, отображение радара и навигационный звук. Механика обновлений
и выдачи прав согласована с F515 Geofence и Vega Monitor. В комплекте находится
нужный код; эти соседние приложения не являются зависимостями сборки.

## Закрытые компоненты, которые сюда не включены

| Компонент | Зачем нужен | Как используется |
| --- | --- | --- |
| Qualcomm SNPE 1.55.0.2958 | Заголовки C++ и инструменты преобразования модели | Получить отдельно; импорт/readonly mount |
| Qualcomm QCARCAM 4.7 headers | ABI штатной камеры AIS | Получить отдельно; импорт двух заголовков |
| QNX/Qualcomm runtime libraries | Линковка с библиотеками конкретной прошивки | Из своей прошивки/ГУ, импорт с SHA-256 |
| Android SDK/NDK, JDK, LLVM | Средства сборки | Установить отдельно по их лицензиям |

QCARCAM-заголовки в исходном рабочем каталоге помечены Confidential and Proprietary;
SDK SNPE и библиотеки прошивки не объявляются открытым кодом этого проекта.
Они не включены ни в Git, ни в APK. APK использует уже имеющиеся на ГУ библиотеки.
Скрипты и контрольные суммы для импорта находятся в `native/`.

В репозитории нет ключей ADB, ключа подписи официального APK, паролей,
Telegram/GitHub-токенов, SSH-ключей, конфигурации личных серверов и записей камеры.
Готовые APK не приложены: они содержат встроенный ключ ADB. Официальный APK
распространяется по отдельной ссылке на сайте, локальный собирается со своим ключом.
